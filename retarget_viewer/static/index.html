손

리타겟 방식

다른 방식 결과를 옆에 반투명으로
PIP×1.3·DIP×1.7, 검지−40°·중지−30° (장갑용 값)
엄지만 손끝 최적화 결과 사용(핀치 대립용)
Tesollo 매핑 = tesollo_ros2 manus_retarget.py 공식을 Quest 관절각에 적용(손끝 최적화 없음). 엄지: thumb1 = 손바닥 평면 안 벌림각 + 오프셋, thumb2 = −1.6×(손바닥 쪽 들림각 − 중립).

입력

왼손 로봇 = 오른손 URDF 의 거울상(DG-5F LEFT 는 RIGHT 의 거울). 합성 입력은 오른손 자세를 거울로 뒤집어 왼손으로 쓴다.
-
Manus Metagloves 를 이 서버(ro1)에 꽂힌 동글로 직접 읽는다(SDK Integrated, 읽기만). 다른 Manus 프로그램(예제·대시보드)은 꺼 둘 것. 위 '사람 손' 선택에 맞는 장갑(오른손/왼손/양쪽)을 쓴다. Tesollo 공식 매핑은 장갑의 관절각(ergonomics)을 그대로 쓴다.
-
실물 DG-5F 관절각을 읽기만 해서(손에 명령 0) 변환 없이 URDF 에 그대로 띄운다 — 와이어°=URDF° 확인용. 손을 webctl 이 잡고 있으면 webctl 값을 대신 읽는다(갱신 ~5초). 손가락을 손으로 움직여 화면과 같은 방향인지 볼 것.
-
범위 측정
초기화 → 관절마다 손으로 양쪽 끝(멈추는 곳)까지 천천히 밀었다 놓기 → 저장. 측정 칸이 URDF·매뉴얼보다 넓으면 주황.
